UMBRAL WEB
Jerarquía visual para páginas con mucho contenido
Código: UW01 | Versión: 1.0 | Fecha: 27 de octubre de 2026
Tipo: Nota de diseño
Área responsable: Diseño y experiencia de usuario

Una página con mucho contenido necesita un orden de lectura reconocible. La propuesta visual debe distinguir el mensaje principal, los datos de apoyo y la acción que se espera del visitante. Si todos los elementos tienen el mismo tamaño o contraste, la composición pierde dirección.

Como referencia para futuras interfaces, se propone una composición editorial: un título dominante, bloques de información cortos y espacio libre entre secciones. La tipografía puede aportar personalidad sin obligar a cambiar toda la estructura. Las imágenes deben acompañar el contenido, no desplazar la información que el usuario necesita.

Esta referencia resulta útil para páginas de servicios y catálogos. Antes de adoptarla, el equipo debe revisar la composición en una pantalla pequeña y comprobar que el orden visual siga siendo claro. La intención es explorar una identidad distinta conservando una lectura sencilla.
